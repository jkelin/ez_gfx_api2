# ez-gfx-runtime

Compiler-free execution boundary for contexts, frame recording, indirect commands, compiled frame graphs, shader artifacts, native texture decoding/residency, descriptors, render targets, caches, uploads, and host-polled events. Shader load accepts artifacts containing any nonempty target subset, selects only the requested backend, and fails with `MissingProduct` when that backend is absent; it never falls back to another target. Selected backend/stage reflection is parsed and validated exactly once before any native shader call. Metal product selection rejects incompatible platform, architecture, minimum OS, language, and metallib contract metadata deterministically. The runtime never links Slang or performs JIT compilation.
