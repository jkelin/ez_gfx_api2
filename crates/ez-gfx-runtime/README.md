# ez-gfx-runtime

Compiler-free execution boundary for contexts, frame recording, indirect commands, compiled frame graphs, shader artifacts, native texture decoding/residency, descriptors, render targets, caches, uploads, and host-polled events. Shader load parses and validates every selected backend/stage reflection exactly once, including named bindings, physical ranges, cross-stage consistency, texture heaps, and pipeline layout, before any native shader call. Metal product selection rejects incompatible platform, architecture, minimum OS, language, and metallib contract metadata deterministically. The runtime never links Slang or performs JIT compilation. Packaging and `xtask export-parity` fail on compiler dependencies while preserving normal OS and graphics dependencies.
