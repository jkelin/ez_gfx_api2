# ez-gfx-artifact

Compiler-free `.ezgfxshader` types shared by the offline compiler and runtime. Format v5 uses a fixed 56-byte little-endian frame containing magic, explicit version, reserved flags, payload length, and BLAKE3 digest followed by one `rkyv` payload. It identifies each logical shader by `(stage, entry-point name)`, allowing same-stage names while rejecting duplicate target products. Compute-stage reflection requires fixed nonzero workgroup dimensions. Decode caps the full file at 64 MiB, verifies framing and digest, bytechecks aligned bytes, then preflights archived collection counts, strings, metadata, provenance, and variant ranges before owned deserialization. Artifact invariants require nonempty target bytecode, unique products, complete target coverage for every entry point, matching compiler provenance targets, portable SPIR-V/DXIL contracts, and explicit Metal compatibility.
