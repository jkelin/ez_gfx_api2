# ez-gfx-artifact

Compiler-free `.ezgfxshader` types shared by the offline compiler and runtime. Format v3 uses a fixed 56-byte little-endian frame containing magic, explicit version, reserved flags, payload length, and BLAKE3 digest followed by one `rkyv` payload. Decode caps the full file at 64 MiB, verifies framing and digest, bytechecks aligned bytes, then preflights archived collection counts, strings, metadata, provenance, and variant ranges before owned deserialization. Owned validation infers the nonempty selected concrete target-product set from the artifact union and requires every declared stage to contain that exact set, plus one entry point per stage and target/profile/compatibility uniqueness. MSL and metallib are distinct concrete products. Runtime depends only on this crate and selects requested backends without compiler fallback.
