# ez-gfx-artifact

Compiler-free `.ezgfxshader` types shared by the offline compiler and runtime. Format v3 uses a fixed 56-byte little-endian frame containing magic, explicit version, reserved flags, payload length, and BLAKE3 digest followed by one `rkyv` payload. Decode caps the full file at 64 MiB, verifies framing and digest, bytechecks aligned bytes, then preflights archived collection counts, strings, metadata, provenance, and variant ranges before owned deserialization. Owned validation enforces stage entry points, target/profile/compatibility uniqueness, and SPIR-V/DXIL/Metal coverage. Target products carry explicit Vulkan SPIR-V, DX12 Shader Model, MSL language, or metallib platform/architecture/OS/SDK/language/library/toolchain compatibility. Runtime depends only on this crate and never links Slang.
