# ez-gfx-backend-vulkan

Vulkan 1.3 HAL using `ash`. It owns instance/device/queues, timeline uploads, allocator-backed images, update-after-bind sampled-image descriptors, layout transitions, configurable swapchains, and GPU readback. Presentation reports the surface's FIFO, mailbox, immediate, relaxed, and extension-gated FIFO-latest-ready modes exactly; mode changes recreate the swapchain. Native handles stay behind runtime/FFI boundaries.
